# Bosun 0.4.0

- Перестроено меню Decky: быстрые CPU/TDP и действия сверху; CPU/GPU policy, эксперименты, строки запуска, readback, автоматика и обслуживание — в сворачиваемых разделах. Сворачивание сохраняет редакторы и черновики.
- Игровые основы фильтруются по runtime-ключам. Boot, zram-конфигурация, SMT, LAVD, mount/memlock остаются глобальными. Параметры запуска Steam выделены отдельно и действуют после перезапуска игры.
- Новый Desktop GUI на Qt/PySide6 в духе Helmsman: боковая навигация, карточки, поиск/группы настроек, общие и игровые назначения, свои профили, импорт/экспорт, диагностика, обновление и откат. Используется тот же backend и журнал, окно работает от обычного пользователя с системной авторизацией для операций.
- Установщик подготавливает отсутствующие Qt/PySide6 и polkit через настроенные SteamOS repositories с восстановлением RO. Проверяет настоящий импорт QtWidgets, не наличие необязательных Qt-tools. Ярлык запускает GUI без терминала.
- Удаление назначения другой игры больше не завершает текущую игровую сессию.
- README переоформлен вокруг установки и интерфейсов; подробное CLI-руководство сохранено отдельно.

Проверено: 136 Python-тестов, 32 frontend-теста исходников и поставляемого bundle, TypeScript/build; реальные Qt-виджеты с изолированным backend (preview/apply/readback/rollback, игровое применение, сохранение черновика, отмена авторизации, пять страниц при 1280×800 и 960×600). Установка/обновление/удаление проверены fixtures. Физического Deck нет: native фокус/события Steam, установка пакетов SteamOS и аппаратное соблюдение CPU cap требуют проверки на устройстве. Прирост FPS/автономности не заявляется.

Обновление: запустите свежий `Bosun-installer.desktop` либо `python3 /home/.bosun/app/install.py --update`. Профили и исходные значения сохраняются. После завершения заново откройте Bosun/Decky.
