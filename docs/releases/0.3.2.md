# Bosun 0.3.2

Исправлена ошибка `Generated GRUB has no Linux entries` при применении рекомендуемого профиля. Проверка Bosun теперь распознаёт используемую SteamOS загрузочную команду `steamenv_boot linux …`, а также обычные `linux`/`linuxefi`.

Сохранены `grub-script-check`, проверка наличия запрошенных параметров в строке загрузки ядра, проверка внешнего изменения EFI-конфига перед записью, recovery-copy и возврат исходного read-only режима. Отказ с указанной ошибкой происходил до замены EFI-конфига.

Добавлены шесть проверок production-пути генерации GRUB: применение/повтор/откат, прямые и SteamOS loader-команды, отбраковка comments/echo, отсутствие запрошенного параметра, ошибка syntax checker и конкурентное изменение EFI-файла. Внешние команды генератора эмулируются, проверки и запись выполняются реальным кодом в изолированном дереве. Физического Steam Deck в среде разработки нет.

Обновление: Desktop Bosun → «Обновить Bosun», Decky → «Обновить Bosun и плагин» либо повторный запуск свежего `Bosun-installer.desktop`. Затем повторите применение профиля; после успешного изменения boot-параметров нужна перезагрузка. Сохранённые профили и журнал отката сохраняются.
