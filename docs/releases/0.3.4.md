# Bosun 0.3.4

Исправлены кнопки, смещённые вправо в Gaming Mode: действия теперь используют штатный режим на всю ширину и отдельные строки Decky. Длинные списки и ползунки размещены под подписью. Исправлена также разметка редактора параметров запуска Steam.

Исправлена потеря выбора при скрытии/возврате бокового меню: Bosun включает штатный флаг Decky `alwaysRender`, который сохраняет форму, незавершённые callbacks списков и их элементы. В 0.3.3 защищался только черновик внутри уже смонтированного React-компонента; удаление всего компонента самим Decky оставалось неучтённым. Постоянный опрос или отдельный сервис для этого не добавлены. Выход из самого плагина по кнопке назад по-прежнему закрывает несохранённый черновик.

Под настройками расположен блок «Фактическое состояние устройства»: отдельно показаны ожидаемые и прочитанные значения с отметкой совпадения/расхождения. CPU cap отображается в MHz, TDP APU — в W. Есть ручное обновление чтения; выбранное значение в черновике само по себе не объявляется применённым.

Проверено: 114 Python-тестов, 26 frontend-тестов, TypeScript и готовая сборка Decky. Новые проверки выполняются как над исходниками, так и над поставляемым bundle: моделируется жизненный цикл видимости из Decky PluginView, callback выбора во время скрытия, сохранение того же элемента списка, черновики системных и launch-параметров, передача выбранных значений в применение, полноширинная разметка и независимое отображение readback. На 0.3.3 четыре проверки hide/show и разметки воспроизводили ошибки. Native UI Steam, графическая геометрия и работа настоящих драйверов в среде разработки недоступны; аппаратная проверка на LCD/OLED ещё требуется.

Обновление: Desktop Bosun → «Обновить Bosun», Decky → «Обновить Bosun и плагин» либо повторный запуск свежего `Bosun-installer.desktop`. Decky перезапустится; проверьте 0.3.4 в заголовке Bosun. Профили и журнал отката сохраняются. Для этого исправления перезагрузка SteamOS не требуется.
