# Bosun 0.3.1

Исправлена постоянная ошибка `Permission denied: '/home/.bosun/state/lock'` в Gaming Mode. В manifest Decky исправлен флаг `_root` на `root`: плагин управления системой теперь получает нужные права. При запуске без них показывается понятная причина и способ восстановления.

Обновление с 0.3.0: запустите свежий **Bosun-installer.desktop в Desktop Mode**. Старая кнопка обновления внутри Decky тоже затронута нехваткой прав; desktop-установщик исправляет manifest и перезапускает Decky. Сохранённые профили, исходные значения и журнал отката остаются на месте.

`/home/.bosun` — общий root-owned каталог программы и системного журнала на writable-разделе SteamOS. Пользовательские CLI-профили находятся в `~/.config/bosun/profiles`. Менять права каталога или переносить его для исправления этой ошибки не требуется.

Добавлена проверка с отдельным Linux-процессом и настоящими Unix permissions: после установки флаг manifest выбирает UID backend по контракту Decky, проверяются доступ к защищённому lock, сохранение профиля, применение и откат в изолированном дереве. Отдельно проверяется понятный отказ без root. Физического Steam Deck в среде разработки нет.
