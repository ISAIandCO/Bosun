# Bosun 0.4.2

Исправлена оставшаяся блокировка «CLI launcher owns the active profile» при изменении глобальных настроек. Исправление 0.4.1 охватывало только сессии Decky; теперь глобальный профиль заменяет также CLI-launcher и старые записи без указанного владельца. Искать token или делать полный откат для этого больше не требуется.

- Новый профиль и завершение временной сессии фиксируются вместе в журнале. При ошибке или внешнем конфликте сохраняется возможность восстановления.
- Поздний выход старого launcher не возвращает прежние настройки и не завершает новую игровую сессию. Игра продолжает работать, её код завершения сохраняется.
- Предпросмотр остаётся без записи. В Desktop отображается сохранённая игровая сессия любого типа; это не утверждение, что игра запущена.
- Игровые назначения и исходные значения для отката сохраняются. Неизвестные токены по-прежнему отклоняются; история заменённых сессий ограничена 64 записями, фонового мониторинга нет.

Проверено: 150 Python-тестов, 32 frontend-теста, TypeScript/build, Qt с изолированным backend, включая воспроизведение CLI-ошибки и реальный дочерний процесс launcher. Физического Steam Deck нет; аппаратные замеры не выполнялись.

Обновление: `python3 /home/.bosun/app/install.py --update`, затем закройте и заново откройте Bosun и повторите применение глобального профиля. Подходит и повторный запуск актуального desktop-установщика. Перезагрузка для устранения блокировки не нужна; загрузочные твики по-прежнему требуют её для вступления в силу.
