# Bosun 0.3.3

Исправлен сброс выбранных настроек в Decky: обновление состояния, предпросмотр и уведомления Steam больше не заменяют несохранённый черновик прежним профилем. Ошибка сохранения также не стирает введённые значения. Выбранная основа профиля теперь отображается в списке; черновик можно явно сбросить к сохранённым настройкам.

Кнопка «Сохранить и применить к текущей игре» расположена рядом с основными настройками. Она сохраняет назначение и передаёт новые значения запущенной игре при включённых автоматических профилях. Результат применения, включая SKIP/CONFLICT, показан рядом с кнопками. Выключенная автоматика явно обозначает сохранение без применения; включение применяет назначение текущей игре. Несохранённые изменения отмечены в интерфейсе, элементы блокируются на время операции.

Проверено: 114 Python-тестов, 20 frontend-тестов, TypeScript и сборка готового Decky bundle. Девять новых React-тестов воспроизводят действия пользователя с настоящим компонентом плагина; native Decky UI/RPC подменены. Python-регрессия проверяет изменение активного назначения и возврат исходного CPU cap в изолированном sysfs. Физического Steam Deck в среде разработки нет: отображение реальным Steam-клиентом и записи в настоящие драйверы требуют аппаратной проверки.

Обновление: Desktop Bosun → «Обновить Bosun», Decky → «Обновить Bosun и плагин» либо повторный запуск свежего `Bosun-installer.desktop`. Decky перезапустится; в заголовке плагина должна появиться версия 0.3.3. Сохранённые профили и журнал отката сохраняются. Для этого исправления перезагрузка SteamOS не нужна.
