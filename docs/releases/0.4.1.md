# Bosun 0.4.1

Исправлена ошибка «Close the game or stop its profile before changing the global profile» при применении настроек в Desktop Mode без запущенной игры. Раньше блокировка зависела от сохранённой записи сессии Decky: пропущенное событие выхода оставляло её активной до перезагрузки или полного отката.

Теперь явное применение глобального профиля заменяет временный профиль Decky одной транзакцией. Исходные значения и игровые назначения сохраняются; полный сброс и перезагрузка для снятия этой блокировки не нужны. Предпросмотр предупреждает о замене и ничего не записывает. В Обзоре показана оставшаяся запись назначения, без утверждения, что игра действительно запущена.

Обработка внешних конфликтов, ошибок записи и восстановления журнала сохранена. При неуспешном переходе запись сессии остаётся для восстановления. Сессия CLI-launcher по-прежнему защищена от смены глобального профиля до её завершения. Desktop, Decky и CLI используют общий переход.

Проверки: 143 Python-теста, 32 frontend-теста, TypeScript/build и реальные Qt-виджеты на изолированном backend, включая воспроизведение этой ошибки. Физического Steam Deck нет; аппаратные замеры производительности не выполнялись.

Обновление: `python3 /home/.bosun/app/install.py --update`, затем заново откройте Bosun и примените нужный глобальный профиль. Также подходит повторный запуск актуального desktop-установщика.
