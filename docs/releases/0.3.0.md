# Bosun 0.3.0

Устанавливаемая версия для SteamOS с управлением из Desktop и Gaming Mode. Физические Steam Deck LCD/OLED ещё не прошли аппаратную приёмку; измеренный прирост FPS или автономности не заявляется.

* Recommended: `mitigations=off`, NMI watchdog off, zram page-cluster 0, все три компонента MGLRU, THP defrag `defer+madvise`, `/home` noatime и отключение zswap только при исключительно zram swap. Условия и no-op показываются в preview.
* Отдельные настройки памяти/compaction/writeback, NVMe/SD/zram, AMD P-state, GPU scheduler, USB polling и memlock; новые профили memory-throughput, streaming, io-throughput, background-overhead.
* LAVD autopilot/balanced/powersave/performance с проверкой фактического бинарника и корректным восстановлением режима при ошибке.
* Decky: чтение/редактирование/восстановление настоящих Steam launch options, отдельные резервные копии по аккаунту и игре; пресеты Mesa cache, Proton sync, DXVK latency, RADV flags, I/O priority и CPU affinity. Системный помощник не исполняет строки игр.
* Проверка внешних изменений, recovery после прерванной записи, полный откат с восстановлением строк Steam. Отсутствующие необходимые утилиты устанавливаются из native repositories; RO автоматически возвращается в исходный режим.
* Глобальный отбор методов и сравнение с SDWEAK: [docs/global-analysis.md](https://github.com/ISAIandCO/Bosun/blob/v0.3.0/docs/global-analysis.md). Полный каталог: [docs/catalog.md](https://github.com/ISAIandCO/Bosun/blob/v0.3.0/docs/catalog.md).

Проверено: 106 Python-тестов, 11 frontend-тестов, TypeScript, сборка Decky, systemd units и распаковка устанавливаемого архива. Аппаратная A/B-процедура включена в документацию.

Установка/обновление: скачайте `Bosun-installer.desktop` и запустите в Desktop Mode. Для установки именно этой версии распакуйте `Bosun-0.3.0.tar.gz`, затем запустите `python3 Bosun-0.3.0/install.py --source Bosun-0.3.0`. Node/npm на Deck не нужны. Контрольные суммы — `SHA256SUMS`.

Откат: Decky → Bosun → «Полный откат, включая параметры запуска Steam». Если редактировались строки нескольких Steam-аккаунтов, сначала восстановите строки в каждом из них. Без управляемых строк Steam: `~/.local/bin/bosun rollback`. Для boot/zram/memlock изменений требуется перезагрузка. Подробности установки, обновления, аппаратные ограничения и A/B-процедура — в [README](https://github.com/ISAIandCO/Bosun/blob/v0.3.0/README.md).
